# agents-verstka-pack

Стартовый шаблон вёрстки: **Vite + Pug + SCSS + JS-модули** с правилами для AI-агентов (Claude Code, Cursor). Вёрстка многостраничная, готова к переносу в CMS (1С-Битрикс, WordPress).

## Быстрый старт

```bash
npm install
npm run dev
```

`http://localhost:5173` — карта страниц проекта.

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | сервер разработки |
| `npm run build` | сборка в `build/` (HTML + ассеты с хешами) |
| `npm run build:cms` | сборка для CMS: без хешей, относительные пути, без HTML. Папка — `CMS_OUT_DIR` в `.env.cms.local` |
| `npm run preview` | просмотр сборки |
| `npm run images` | webp рядом с каждым jpg/png в `src/assets/img` (`-- --avif` — ещё avif) |
| `npm run visual` | снимки страниц на 390–2560 в `.tmp/visual/` и проверки масштаба (первый раз — `npx playwright install chromium`) |
| `npm run thumbs` | превью страниц для карты страниц из экранов макета `design/screens/desktop/` |

## Что есть в шаблоне

- **Масштаб десктопа.** Десктоп верстается в пикселях макета и масштабируется через `zoom` на 1280–1920; на широких экранах фоны и ленты — до краёв. Параметры — `src/styles/variables.scss`, правило — `.agents/rules/desktop-scale.mdc`.
- **Данные в JSON.** `src/data/*.json` доступны в Pug как `data.<имя>` — структура повторяет будущие записи CMS.
- **Миксины подключаются сами**: файл в `src/components/mixins/` — и миксин доступен везде.
- **Ленивая загрузка библиотек.** Swiper, Fancybox и их CSS грузятся, только если блок есть на странице и подошёл к экрану. Пустая страница — около 3 КБ JS и 4 КБ CSS.
- **Картинки**: `+picture` с avif/webp, размерами и ленивой загрузкой; `npm run images` готовит пары.
- **Скрипты страниц** по `body[data-page]`, а не по адресу — работает в CMS.
- **Визуальная проверка** на Playwright: прокрутка вбок, совпадение краёв контента, масштаб.
- **Карта страниц** (`index.html`): сводка готовности, разделы, карточки с превью из макета и прогрессом. Готовность — мета `@progress` страницы, план — `src/data/sitemap.json`.

## Правила

| Файл | Что |
|---|---|
| `AGENTS.md`, `CLAUDE.md` | вход для агентов |
| `docs/ai/project-rules.md` | структура, команды, данные, ассеты, проверка перед сдачей |
| `docs/ai/pug-rules.md` | разметка, миксины, картинки, данные |
| `docs/ai/scss-rules.md` | стили, BEM, переменные, миксины |
| `docs/ai/js-rules.md` | модули, ленивая загрузка, масштаб в JS |
| `.agents/rules/*.mdc` (копия — `.cursor/rules/`) | короткие правила и `desktop-scale.mdc` |
