# CLAUDE.md

Ты работаешь с проектом верстки на Vite + Pug + SCSS + JavaScript modules.

## Перед началом работы

Всегда изучи текущую структуру проекта и существующие паттерны.

Основные правила находятся здесь:

- `docs/ai/project-rules.md`
- `docs/ai/pug-rules.md`
- `docs/ai/scss-rules.md`
- `docs/ai/js-rules.md`

## Ключевые ограничения

- Разметка пишется только на Pug.
- Стили пишутся только на SCSS.
- JavaScript пишется модульно и подключается через `src/scripts/main.js`.
- Каждая секция создается отдельным файлом в `src/components/sections/`.
- Если секция переиспользуется с разным контентом, она переносится в `src/components/mixins/` и оформляется как Pug mixin.
- Каждый SCSS-файл компонента отвечает за один BEM-блок.
- Шрифты всегда локальные: `src/assets/fonts/`.
- Изображения всегда в `src/assets/img/`.
- В `public/` должен быть только `robots.txt`.

## После изменений

Проверь:

- нет дублирования Pug-разметки;
- новая секция подключена через `include` или `mixin`;
- для новой секции есть SCSS-файл;
- SCSS-файл подключен в `src/styles/styles.scss`;
- медиазапросы используют миксин;
- цвета вынесены в переменные, если используются повторно;
- JS-логика вынесена в отдельный модуль, если она не тривиальная.
